GLYPH EDITOR for ANDROID (Kotlin) - type normal keys, see your own glyphs.

1. Install Android Studio, then File > Open > this folder, wait for Gradle sync.
2. Run on your phone/emulator, or Build > Build APK(s) for a single portable app-debug.apk.
3. Your glyphs: app/src/main/assets/glyphs/ (glyphs.txt + PNGs, built into the app)
   or your own folder: set GLYPH_FOLDER in app/src/main/java/com/glypheditor/Config.kt
   or the app's own folder: Android/data/com.glypheditor/files/glyphs
See GlyphEditorAndroid_Guide.pdf.
